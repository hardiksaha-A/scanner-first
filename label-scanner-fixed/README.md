# Label Scanner (v0.8, fixed)

Push this folder to your GitHub repo (main/master). The "Build APK" workflow builds it;
download the APK from the run's Artifacts (LabelScanner-APK).

## Install
Uninstall the old app first (old builds were signed with a different key). Then install the new APK.
In the app, tap **Take photo of ingredients** to scan an ingredient list.

## Optional: make future updates install over the old app (keeps your data)
Do once, on a computer:
1. keytool -genkey -v -keystore debug.keystore -storepass android -alias androiddebugkey -keypass android -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=Android Debug,O=Android,C=US"
2. base64 -w0 debug.keystore   (copy the output)
3. GitHub repo > Settings > Secrets and variables > Actions > New secret, name DEBUG_KEYSTORE_B64, paste the output.

## Notes
- OCR engine files (www/vendor/tess) and the android/ folder are generated by the build. Do not add them.
- Keep package-lock.json committed (the build uses npm ci).
